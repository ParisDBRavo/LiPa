# Imágenes

Guarda aquí tus fotos con estos nombres exactos (.jpg). Reemplazan automáticamente los placeholders:

- `hero.jpg` (1920×1080)
- `portfolio-1.jpg` … `portfolio-8.jpg` (1 y 5 verticales, 4 horizontal)
- `service-portrait.jpg`, `service-lightpainting.jpg`, `service-events.jpg`, `service-product.jpg` (4:5)
- `video-cover.jpg` (16:9)
- `studio.jpg` (3:4)

Tip: optimiza las imágenes (~300 KB cada una, máx. 2000 px de ancho) para que cargue rápido.
